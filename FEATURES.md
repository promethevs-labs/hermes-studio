# Features
Hermes is a personal study workspace: a Next.js hub over a course shortlist, a tutoring loop that keeps a measured model of what you know, a studio where agents draw diagrams and make videos, and a catalog (one SQLite file) that holds the content and the learner record.

Statuses describe implemented capabilities, not verification of a live deployment. Studio API paths below name the loopback runner routes, exposed to the browser under `/studio/api/`. Media tools require separately initialized submodules; those tool directories are empty in this worktree, so their rendering capabilities are documented integrations, not verified tool implementations here.

- **Signed-in gate**: protected pages and API routes (excluding `/`, `/sign-in`, `/api/auth/*` and static files) send a signed-out visitor to sign in (pages) or refuse them (API). Status: stable.
